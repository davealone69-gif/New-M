## ZERO-TRUST REAL BUILD & CODE GENERATION DIRECTIVES

### 1. ZERO-MOCK & ZERO-SYNTHETIC POLICY
- **Real Business Logic Only**: Never output stubbed functions, `// TODO` comments, fake mock arrays, or simulated binaries.
- **Authentic Build Output**: All feature modules, agents, code generators, and API handlers must execute fully with real reactive state and server-side model calls.
- **No Unverifiable Reports**: Every view and function must be demonstrable and interactive.

### 2. CODE QUALITY & COMPLETENESS DIRECTIVES
- **100% Fully Written Code**: Every view, function, handler, and state flow must be fully written out end-to-end without mid-file truncation or omitted blocks.
- **Self-Contained Declarations**: Include all required package declarations, imports, types, interfaces, and state handlers across React, Express server endpoints, and agent orchestrators.
- **Reactive State Management**: Use explicit, reactive state management across all dynamic screen layouts and user interactions.

### 3. NAVIGATIONAL & REACHABILITY STANDARDS
- **Full Screen Reachability**: Every feature module (Swarm Builder, Core Gemini AI, Free LLM Hub, Training Centre, Synthesis Manifest, Custom Agent Synthesizer, APK/Code Auditor & GitHub Exporter) must be reachable directly from the main OS navigation bar/rail.
- **Interactive Controls**: Buttons, inputs, sliders, switches, terminal consoles, and search filters must be wired up to actual state mutators and backend routes.

### 4. ENVIRONMENT & SERVING CONFIGURATION
- **Server Binds**: Web/Express server entry points must bind to `0.0.0.0` on port `3000`.
- **Server-Side Gemini API**: All Gemini calls must run on the server side using `@google/genai` with `GEMINI_API_KEY`.
